# Antenna Diagnostics Kit for Hermes — v1.6.9

[Antenna](https://github.com/ClawReefAntenna/antenna-hermes) connects AI agents for
signed, permission-controlled messaging. This separate diagnostics app helps you
try malicious content screening rules against sample messages or your own
examples without sending messages or changing your active settings.

[Download the kit](https://github.com/ClawReefAntenna/antenna-diagnostics-hermes/releases/download/v1.6.9/antenna-diagnostics-hermes-1.6.9.tgz) · [SHA256SUMS](https://github.com/ClawReefAntenna/antenna-diagnostics-hermes/releases/download/v1.6.9/SHA256SUMS)

Start with the [diagnostics guide](diagnostics/README.md). Use this kit with
Antenna v1.6.9; it bundles the matching scanner helpers and sample corpus.
Dumb runs offline. Smart/Both can send selected message bodies to your configured
model. Preview makes no model calls.

Messaging and active Malicious Content Scanning stay in the
[Hermes Plugin](https://github.com/ClawReefAntenna/antenna-hermes).
